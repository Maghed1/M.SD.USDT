# مِسْكَال — منصة الدولار الرقمي (نموذج تجريبي)

هذا مشروع React جاهز للتشغيل محليًا أو النشر مباشرة أونلاين.

## التشغيل محليًا
```bash
npm install
npm run dev
```
يفتح الموقع على `http://localhost:5173`

## النشر على الإنترنت (الطريقة الأسهل — Vercel)
1. ارفع هذا المجلد كـ repository جديد على GitHub
2. روح إلى https://vercel.com وسجّل دخول بحساب GitHub
3. اضغط **Add New Project** واختر الـ repository
4. اترك الإعدادات الافتراضية (Vercel يتعرف تلقائيًا أنه مشروع Vite) واضغط **Deploy**
5. بعد دقيقة تقريبًا يعطيك رابط مباشر مثل: `dollar-exchange-app.vercel.app`

## بديل بدون GitHub (أسرع للتجربة فقط)
1. روح إلى https://stackblitz.com أو https://codesandbox.io
2. أنشئ مشروع React/Vite جديد
3. اسحب ملفات هذا المجلد بالكامل داخله (أو الصق محتوى `src/App.jsx`)
4. يعطيك رابط معاينة حي فورًا

## ملاحظة مهمة
هذا نموذج واجهة فقط (Frontend demo) — البيانات (الأرصدة، الطلبات) مخزنة في ذاكرة المتصفح مؤقتًا ولا تُحفظ بعد إغلاق الصفحة. لتطبيق حقيقي يحتاج قاعدة بيانات فعلية (مثل Firebase أو Supabase) وبوابة دفع لتنفيذ عمليات حقيقية.
